\chapter{System Parameters}\label{ch:system-parameters}

Table A.1 is the single source of truth for numerical parameters used in
the final model, controller, simulation, and results. Each value should
carry a method, uncertainty, configuration, and source. A datasheet
value must not silently replace an as-installed or experimentally
identified value.
