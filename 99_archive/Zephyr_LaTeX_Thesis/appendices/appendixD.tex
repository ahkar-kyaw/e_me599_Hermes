\chapter{CAN and Actuator Configuration}\label{ch:can-and-actuator-configuration}

All entries in this appendix must be read from the installed actuator
configuration and released firmware. Manufacturer capability is not
equivalent to the chosen project setting. Node identity should be tied
to a physical wheel label, connector, wheel coordinate, roller sign,
direction multiplier, and encoder zero.
