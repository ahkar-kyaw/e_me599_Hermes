compiler\slash{}toolchain versions, dependency lock or manifest, generated
configuration, parameter file, clean-build transcript, binary checksum,
flash procedure, hardware revision, and automated test output. Short
source excerpts should be added to the thesis only when they clarify an
interface or safety decision better than pseudocode.
