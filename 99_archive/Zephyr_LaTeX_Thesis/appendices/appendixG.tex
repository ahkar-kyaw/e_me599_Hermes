Each protocol requires operator, observer, date, environmental
conditions, hardware revision, firmware commit, parameter checksum,
battery ID\slash{}state, raw-file names, deviations, unsuccessful attempts, and
disposition. Approval signatures and institutional laboratory
requirements should be added where applicable.
